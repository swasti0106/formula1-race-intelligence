# Formula 1 Race Intelligence

An interactive Tableau project that analyses Formula 1 race data across 17 seasons (2010-2026). It covers driver performance, team strategy, circuits, and race conditions.

## Live Project
https://public.tableau.com/app/profile/swasti.sharma3490/viz/F1RACEINTELLIGENCEDASHBOARDANALYSIS/F1RACEINTELLIGENCESTORY

## Visualizations (9 worksheets)
1. Driver Performance - average finish position (bar chart)
2. DNF Analysis - race retirements by driver (treemap)
3. DRS Overtakes - overtakes by year (line chart)
4. Fastest Lap Analysis - fastest laps by driver and year (heat map)
5. Circuit Analysis - total laps by circuit (packed bubbles)
6. Pit Stop Performance - average pit stop time by team (column chart)
7. Tyre Strategy Analysis - common tyre strategies (pie chart)
8. Weather Impact Analysis - air temperature vs. humidity (scatter plot)
9. Team Points Trajectory - team points by season (area chart)
